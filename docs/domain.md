# 领域资料

天堂寨的康养队伍沿初、中、高级步道分段行进。索道临时停运时，已进入山谷的团队与尚未出发的团队处境完全不同，本服务提供完整的分段行程接续能力，让带队人员共享可信的路线占用信息。

## 能力范围

- **路段签到**：带队人员登记队伍实际到达 / 离开各路段的时间。山区断网产生的补报同时保留现场原始时间（`occurred_at`）与服务端上传时间（`uploaded_at`），并标记 `source=backfill`。
- **封闭与疏散通告**：维护人员发布路段封闭与疏散通道变化（`POST /notices`），索道属于 `cableway` 类连接。发布即生效，系统立即重新评估全部在场队伍。
- **队伍分类**：系统按最后已知位置与开放连通图计算受困区域（封闭后不含任何出口的连通分量）。尚未出发（`not_started`）与仍能安全改线（`can_reroute`）的队伍获得替代连接建议；已入谷（`in_affected_zone`）的队伍不提供改线，只登记等待、折返或人工护送决定。
- **接驳占用**：同一出口或同一接驳车辆的 active 预订时间窗不得重叠（首尾相接允许），冲突返回 409；队伍离场后释放预订。
- **游客名单**：仅所属带队人员可读写（`X-Leader-Ref` 与登记的 `leader_ref` 比对），服务不提供跨队伍名单视图。
- **复盘**：`GET /review` 按队伍汇总分类、建议、决定与接驳预订，并以 `exit_account` 说明每支队伍最终如何离开受影响区域。

## 数据约定

`contracts/entities.json` 保存外部交换字段。标识符（`*_ref`）仅表示提交方对同一记录的识别符，示例文件不包含真实个人资料。运行时持久化文件由 `DATABASE_PATH` 决定；时间字段使用带时区偏移的 ISO 8601 字符串。带队人员身份以登记为准，本服务未接入统一认证。
